# 🎨 イラスト 色置換・背景透過ツール

このツールは、画像上をクリックすることで  
**特定の色を置換したり、背景を透過できる画像編集ツール**です。

主に **LINEスタンプ制作** を想定して開発していますが、  
PNG / JPG 画像に対応しており、以下のような用途にも利用できます。

- イラストの配色調整
- 背景色の透過
- SNSアイコンの色変更
- 簡単な画像素材の修正

---

## ✨ 主な機能

- クリック色置換（FloodFill）
- クリック背景透過（FloodFill）
- 複数クリック対応
- 編集結果を次のベース画像として継続編集
- 透過が分かりやすいチェッカーボードプレビュー
- PNG形式でのダウンロード

---

## 🚀 使い方

1. 画像をアップロード  
2. モードを選択  
   - クリック色置換  
   - クリック背景透過  
3. 画像上をクリック（複数可）  
4. 「実行」を押す  
5. 問題なければ PNG をダウンロード  

---

## ⚠ 注意

- FloodFill の仕様上、線で完全に囲まれた領域単位で処理されます
- 透過部分はチェッカーボード背景で表示されます
